# ServiceNow AutoPilot

This build introduces two task modes:

- Bulk Tasks — updates the current ServiceNow list view using the list editor.
- Surgical Tasks — fills the current single-record form using the same field names but field-aware behaviors.

## Included behavior strategies
- Direct replace
- Autocomplete first option
- Choice / select

## Notes
- Chrome does not allow an extension to auto-pin itself to the toolbar during install.
- Use Export Projects before uninstalling if you want to restore both Bulk Tasks and Surgical Tasks later.
