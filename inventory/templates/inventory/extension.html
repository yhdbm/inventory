The download is zipped from the server on each request, so it's always the current version. It applies the saved corrections onto the ServiceNow asset list (and imports/views the corrections CSV).

Install it (developer / unpacked)

  1. Click Download extension (.zip) above.
  2. Unzip it. You'll get a folder named inventory-corrections-extension.
  3. Open chrome://extensions in Chrome (or Edge: edge://extensions).
  4. Turn on Developer mode (top-right toggle).
  5. Click Load unpacked and select the unzipped folder.
  6. Pin it from the puzzle-piece menu so the icon is always visible.

To update later: download again, replace the folder contents, then click the reload ↻ icon on the extension card. (If a ServiceNow tab is open, reload that tab too.)

Use it

  1. In this app, go to Corrections and click Export CSV.
  2. Click the extension icon → Import corrections CSV (or open the viewer and import there). Importing replaces any previous data.
  3. Use Open corrections viewer to review the rows and build the ServiceNow list link (Open in ServiceNow).
  4. On the ServiceNow asset list tab, click the extension icon → Apply corrections to this page. It double-clicks each cell, selects/types the expected value and saves. Committed cells turn green.
  5. Field edit strategies ⚙️ lets you set how each field is edited (dropdown vs text input).

Packaging & the Chrome Web Store

“Load unpacked” is the simplest path for internal/developer use. To distribute it as a regular installable extension you have a few options:

  • Pack as a .crx — on chrome://extensions click Pack extension, choose the folder; Chrome produces a .crx + a .pem private key (keep the key to sign future updates). Caveat: modern Chrome blocks installing .crx files dragged in from outside the store for normal users, so this is mainly useful with enterprise policy (below).
  • Chrome Web Store — register a developer account (one-time $5 fee), upload this same .zip, fill in listing details, and submit for review. You can publish as Public, Unlisted (install only via direct link), or Private (restricted to your Google Workspace org). This is the only way normal users get one-click install + auto-updates.
  • Enterprise force-install — via Google Admin console (or Windows group policy ExtensionInstallForcelist), IT can auto-install the extension org-wide from the Web Store ID, or from a self-hosted .crx + update manifest XML. Best for rolling it out to a team without the public store.

Note: this extension needs the host permission for https://your-instance.service-now.com/* (already in its manifest). Web Store review may ask you to justify that permission.
