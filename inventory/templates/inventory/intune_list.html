Intune re-enrollment steps

Click to expand · scan or click the code on the highlighted side of each step

  1. Delete device from Intune

  2. Remove device's enrollment

  3. Open CMD

    Shift + F10

  4. Go to Installing PowerShell on Windows a

    start msedge https://learn.microsoft.com/en-us/powershell/scripting/install/installing-powershell-on-windows?view=powershell-7.5

  5. Download the installer

    Click on the "PowerShell-7.5.2-win-x64.msi" link to download it.

  6. Go back to CMD and run pwsh.exe b

    "C:\Program Files\PowerShell\7\pwsh.exe"

  7. Net.ServicePointManager c

    [Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12

  8. -ExecutionPolicy Bypass d

    pwsh.exe -ExecutionPolicy Bypass

  9. Net.ServicePointManager, again c

    [Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12

  10. Autopilot e

    Install-Script -name Get-WindowsAutopilotInfo -Force

  11. ExecutionPolicy f

    Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned

  12. Group tag: WH1-ScreenPrint

  13. Group tag: WH1-OutofScope

  14. Group tag: WH1-Shipping

  15. Finish enrollment

    Go back to "Please review the License Agreement" → Accept → type Grouptag-SERIALNUMBER
