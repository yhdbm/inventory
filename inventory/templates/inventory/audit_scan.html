Planned audits — how it works

What it does

Draws a random sample of this site's inventory at the percentage you choose, so you can spot-check it and mark each asset Pass or Fail. Each approved sample is saved as a report.

Filters — what is never sampled

  • Only the current site's assets (the warehouse shown in the navbar).
  • State Retired, Missing or In transit.
  • RF mobiles (model contains MC930B), in any state.
  • In stock assets whose Name puts them in a container outside the IT office: IT Storage A/B/D/E/G/H/J… (any “IT Storage” followed by a suffix, including Floor), the bare G or D, Outside Rack and Waste Container. Plain IT Storage is the IT office, so it is sampled.

Rotation: an asset whose latest result in this site's earlier reports is Pass is not sampled again. Assets that failed (or were never marked) stay eligible, and an asset that failed and later passed counts as passed. Deleting a report removes its results from this check.

The sample size is the percentage of what is left, rounded up, and at least 1 asset.

Steps

  1. Enter the Sample % (1–100, default 2) and click Create sample. This only shows a draft (dashed amber box) — nothing is saved yet.
  2. Review the draft, then click Approve audit to save it as a report, or Discard to throw it away. Creating another sample replaces the draft.
  3. Open Reports and click a report's row to show its sampled assets, grouped by State (each group collapsed). Click the row again to hide it.
  4. Mark every asset Pass or Fail. The choice saves immediately and the Pass / Fail / Pending counts in the row update.
  5. Choosing Fail opens a comment box. The + beside Fail reopens it later (it turns red once a comment exists). Switching back to Pass clears the comment.

What the table shows

  • Asset tag (with a ServiceNow link), and under it the serial number, model category and display name. Rows are sorted by Name.
  • Name (for In stock assets, where the device is), Station ID, GL account, Location and Assigned to.
  • green = GL account contains 202606; red = it doesn't (including a blank GL account).
  • Values are a snapshot from when the report was approved, so later ServiceNow imports don't change it.

Report names

Named by date, e.g. 20261008. Further reports the same day become 20261008-1, 20261008-2…

Who can see and change what

  • A report is private: only the person who approved it and administrators can see it.
  • Creating, approving and marking results need an account with edit rights; without them the radios and buttons are disabled.
  • Administrators can delete a report (🗑 in the list); this removes its results and comments.
